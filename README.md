# Task Manager API

REST API для управления проектами и задачами.

Пользователи могут создавать проекты и задачи, добавлять комментарии и теги, а также использовать фильтрацию, поиск, сортировку и пагинацию.

## Стек технологий

- Python 3.13
- Django 6
- Django REST Framework
- PostgreSQL
- Redis
- Celery
- Docker / Docker Compose
- pytest / factory-boy

## Реализованный функционал

- JWT-аутентификация
- Пользователи
- Проекты
- Задачи
- Комментарии
- Теги
- Фильтрация задач
- Сортировка
- Поиск
- Пагинация
- Кеширование (Redis)
- Выполнение фоновых задач (Celery)
- 20 API-тестов

## Запуск

- git clone https://github.com/Matokhin/task_manager.git
- docker compose up --build

API будет доступно по следующему адресу: http://localhost:8000

## Основные эндпоинты

- POST /api/users/register/ - регистрация
- POST /api/users/token/ - получение JWT-токена
- GET  /api/users/me/ - текущий пользователь
- GET/POST /api/projects/ - список и создание проектов
- GET/POST /api/tasks/ - список и создание задач
- GET/POST /api/tasks/{id}/comments/ - комментарии к задаче
- GET/POST /api/tags/ - список и создание тегов
- GET/POST /api/comments/ - список и создание комментариев

## Тесты

Проект содержит 20 API-тестов, проверяющих основные сценарии работы приложения:
- успешная регистрация;
- регистрация с уже занятым email;
- успешное получение JWT-токена;
- создание проекта;
- получение списка проектов;
- недоступность чужого проекта;
- создание задачи;
- попытка создания задачи в чужом проекте;
- фильтрация задач по статусу;
- фильтрация задач по приоритету;
- фильтрация по нескольким параметрам;
- поиск задач;
- сортировка задач;
- пагинация;
- попытка получения несуществующей страницы пагинации;
- создание комментария;
- добавление нескольких тегов к задаче.

Запуск тестов: docker compose exec web pytest
